# New York_ — 심야 재즈바 (Suno 프롬프트 10곡)

> **Eb장조 본조 + C단조(관계조) 3곡, 전곡 88 BPM.** 컬러 악기: 색소폰.
> Eb는 재즈 스탠더드의 홈 키라 음색 정합성 최고 (あつ森/야채상회 실측에도
> Eb/Bb권 빈출). 단 ♭3개라 키 이탈 가능성 있음 — **실측 필수**, 이탈 시
> 실측 키 기준 세트 재정렬도 허용.

## 생성 규칙

1. Suno에서 곡 제목을 아래 제목 그대로 지정해서 생성.
2. 무드 줄에 바 소음/잔 소리 등 SFX 단어 없음 — 의도된 것 (앰비언스는 후반작업).
3. 생성 후 전곡 실측 → ±1~2반음 보정 / ±3 이상 재생성.
4. mp3는 `audio/suno/newyork/`에 저장.

## 생성 후 체크리스트

1. mp3 → `audio/suno/newyork/` (제목 그대로)
2. 전곡 실측 → 보정/재생성 판정 (Eb는 이탈 가능성 있음 — 주의)
3. 세트 순서 = 구성표 순서
4. 앰비언스(낮은 대화 웅성거림, 먼 사이렌 아주 희미하게)는 세트 조립 후 -12~-18dB
