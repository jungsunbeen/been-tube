# Lisbon_ — 오후의 트램 (Suno 프롬프트 10곡)

> **A단조 본조 + C장조(관계조) 3곡, 전곡 76 BPM.** 컬러 악기: 나일론 기타 (파두 뉘앙스).
> 조표 0개로 안전한 키. 시리즈에 "밝은 낮" 축을 추가하는 영상 (작업용 BGM 수요).
> 단조지만 무드는 따뜻한 saudade — 침울하지 않게.

## 생성 규칙

1. Suno에서 곡 제목을 아래 제목 그대로 지정해서 생성.
2. 무드 줄에 트램 벨/갈매기 등 SFX 단어 없음 — 의도된 것 (앰비언스는 후반작업).
3. 생성 후 전곡 실측 → ±1~2반음 보정 / ±3 이상 재생성.
4. mp3는 `audio/suno/lisbon/`에 저장.

## 생성 후 체크리스트

1. mp3 → `audio/suno/lisbon/` (제목 그대로)
2. 전곡 실측 → 보정/재생성 판정
3. 세트 순서 = 구성표 순서
4. 앰비언스(먼 파도, 거리 웅성거림 아주 희미하게)는 세트 조립 후 -12~-18dB
