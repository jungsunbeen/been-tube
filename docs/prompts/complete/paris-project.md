# Paris_ — 자정의 파리 (Suno 프롬프트 10곡)

> **Bb장조 본조 + G단조(관계조) 3곡, 전곡 72 BPM.** 컬러 악기: 클라리넷.
> 재즈 관악의 홈 키(Bb)라 재즈 어법과 음색 정합성 최고. 1일차 실측에서도
> Suno가 Bb로 자주 수렴했던 키라 순종 기대.

## 생성 규칙

1. Suno에서 곡 제목을 아래 제목 그대로 지정해서 생성.
2. 무드 줄에 카페 소음/거리 소음 등 SFX 단어 없음 — 의도된 것 (앰비언스는 후반작업).
3. 생성 후 전곡 실측 → ±1~2반음 보정 / ±3 이상 재생성.
4. mp3는 `audio/suno/paris/`에 저장.

## 생성 후 체크리스트

1. mp3 → `audio/suno/paris/` (제목 그대로)
2. 전곡 실측 → 보정/재생성 판정
3. 세트 순서 = 구성표 순서, 28분 미만이면 예비 테이크 추가
4. 앰비언스(먼 거리 소음, 드문 발소리)는 세트 조립 후 전체에 -12~-18dB
