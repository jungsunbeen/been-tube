# London_ — 비 오는 런던 (Suno 프롬프트 10곡)

> project.md 포맷 적용: 한 도시 = 키 패밀리 + BPM 고정 (fo.식).
> **D단조 본조 + F장조(관계조) 3곡, 전곡 63 BPM.** 컬러 악기: 펠트 피아노, 뮤트 트럼펫.
> 3분 전후 10곡 → 약 30분 세트 → ×2회 통반복 ≈ 60분.

## 생성 규칙 (시작 전에 읽기)

1. **Suno에서 곡 제목을 아래 제목 그대로 지정**해서 생성 (파일↔목표 매핑 유지).
2. 프롬프트 1번 = 2테이크 → 나은 쪽 채택. 둘 다 좋으면 둘 다 보관 (예비).
3. **무드 줄에 rain/빗소리 단어 없음 — 의도된 것.** 빗소리는 후반작업에서
   세트 전체에 한 레이어로 얹는다 (곡에 베이크되면 트랙 경계 노출 + 실측 오염).
4. D단조는 조표 단순(♭1개)이라 1일차 실패 키들(F#/G#m/Fm)보다 순종 기대.
   그래도 생성 후 전곡 실측 → ±1~2반음 보정 / ±3 이상 재생성.
5. mp3는 `audio/suno/london/`에 저장.

## 생성 후 체크리스트

1. mp3를 `audio/suno/london/`에 저장 (제목 그대로)
2. 전곡 키/BPM 실측 → 목표 대비 판정 (±1~2반음 보정 / ±3↑ 재생성)
3. 채택 테이크 길이 합산 — 세트 28분 미만이면 예비 테이크 추가 또는 Extend
4. 세트 순서 = 위 구성표 순서 (Dm 4곡 → F장조 아치 → 숨 고르기 → 복귀 → 클로저)
5. 빗소리 레이어는 세트 조립 후 전체에 -12~-18dB (Suno 곡에 이미 빗소리가
   섞여 나온 테이크는 탈락 처리)
