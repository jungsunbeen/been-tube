# ggg. 채널 분석 — orange soda. / matcha (검증 완료)

처음 분석에서는 matcha를 "1시간 동안 단계적으로 조옮김하는 변주"로 해석했지만,
두 영상 모두 전곡 스캔으로 재검증한 결과 실제 구조는 다르다 (검증 스크립트: `verify_matcha.py <wav>`).

## 공통 구조: ~30분 믹스 × 2회 반복

| | orange soda. | matcha |
|---|---|---|
| 총 길이 | 60.2분 (3610.6초) | 62.7분 (3760.2초) |
| 실제 구조 | **30.1분 세트 × 2회 반복** | **31.3분 세트 × 2회 반복** |
| 반복 검증 | 절반 오프셋에서 5개 지점 크로마 유사도 모두 1.000 | 동일 (모두 1.000) |
| 시작 | **A장조, 83.4 BPM** | **A장조, 83.4 BPM** |
| 세트 구성 | 트랙 9~10개, 2~4분마다 조성·템포 변화 | 동일 |
| BPM 범위 | 68~99 | 59~86 |
| 조성 경향 | 샤프계 위주 (A, E, F#, G#m, D#m) + D, F | 샤프계(A, B, D, F#) + 플랫계(Cm, Fm, Ab) 혼합 |

- 후반부는 전반부와 같은 오디오를 그대로 반복한 것. "단계적 조옮김 여행"이 아니라
  **서로 다른 트랙을 이어붙인 믹스를 통째로 한 번 더 트는** 구조다.
- 두 영상 모두 A장조 83 BPM에서 시작 → 99g. 채널의 시그니처 사운드 영역 확인.

## 구간별 상세 (matcha, 기존 3개 샘플 지점 재측정)

| 구간 | BPM | 조성/주요 코드 |
|---|---|---|
| 초반 (1분~) | 83 | A장조 — F#m7, C#m7, Dmaj7, A (vi-iii-IV-I) |
| 중반 (10분~) | 86 | D단조/F장조권 — Gm7, Bbmaj7, Fmaj7, Dm7, G7 (C장조 아님; C장조 구간은 19~21분에 따로 있음) |
| 후반 (30분~) | 76 | F단조 (플랫 조성) — Bbmaj7, Abmaj7, Dbmaj7, Fm7, C7 |

※ 기존 분석의 오류: 중반을 "C장조 조옮김(Dm7-G7-C, i-V)"으로 봤지만 C 토닉이 검출되지 않으며,
그 진행이라 해도 표기는 ii-V-I이 맞다. 후반의 "Fmaj7"도 실측은 Fm7(F단조)에 가깝다.
3개 지점만 샘플링하면 우연히 서로 다른 트랙에 걸려 "3단계 구조"처럼 보이니 주의.

orange soda. 1분 구간 코드: Amaj7, E7, Em7, F#m7, Bm7, Dmaj7, A — 역시 A장조권,
E7/Em7이 섞이는 게 특징 (믹솔리디안/블루지한 컬러).

## 소스 곡 수 검증 (analyze_sources.py)

세트 안의 트랙들이 "같은 곡의 피치/템포 변주"인지 확인하기 위해, 각 트랙 구간의
크로마 시퀀스를 12조옮김 × 템포비 0.7~1.4로 정렬해 최대 유사도를 측정했다.

캘리브레이션: 같은 오디오 통반복 구간 0.838 / 같은 곡 다른 구간(matcha 19 vs 21분) 0.817
/ 서로 다른 곡(Paper Sun vs Paper Moon) 0.743 / 합성 +5st 변주 0.969.
→ 같은 곡이면 ~0.8 이상, 다른 곡이면 ~0.75 이하로 갈린다.

결과: **두 믹스 모두 세트 내 모든 트랙 쌍이 0.60~0.78** (음성 기준선 수준)이고,
최적 조옮김·템포비도 무작위로 흩어져 있다. 즉 **피치/템포 변주로 돌려쓴 트랙 쌍은 없다.**
ggg.는 믹스 하나에 **서로 다른 곡 9~12개**를 쓰고, 1시간은 세트 통반복으로만 채운다.

믹스 간 교차 비교(orange soda 12 × matcha 12 = 144쌍)에서도 같은 곡 기준(0.82+)을
넘는 쌍이 없었다 — **두 믹스는 곡을 공유하지 않는다.** 둘 다 A장조 83.4 BPM으로
시작하지만 오프닝끼리도 다른 곡(0.78 미만). 시그니처는 곡 재사용이 아니라
"오프닝은 항상 A장조 83.4 BPM으로 새로 만든다"는 템플릿이다.

## 생성기에 반영할 공식

1. **조성·템포가 다른 2~4분짜리 트랙 9~10개**로 약 30분 세트를 구성한다.
2. 세트를 **2회 반복**해 1시간을 채운다.
3. 시작 트랙은 **A장조 83 BPM**으로 잡는다 (두 영상 공통, 채널 시그니처).
4. 템포는 트랙마다 60~100 BPM 범위에서 다양하게. 조성은 A장조를 홈베이스로
   샤프계(E, B, F#, G#m, D#m)를 중심에 두고, 플랫계(Cm, Fm, Ab, F)를 1~3곡 섞는다.
